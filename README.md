# 🔄 Unit Converter (Konverter Velichin)

Udobnoe i lakonichnoe desktop-prilozhenie na **Python** s sovremennym graficheskim interfeysom na **CustomTkinter** dlya bystrogo perevoda razlichnyh edinits izmereniya.

---

## 🎯 Vozmozhnosti

* 📐 **Perevod edinits:** Dlina, massa, temperatura i drugie velichiny.
* 🎨 **Sovremennyi UI:** Minimalistichnyi temnyi interfeys na CustomTkinter.
* ⚡ **Mgnovennyi raschet:** Pereraschet znacheniy v realnom vremeni pri klike ili vvode.
* 🛡 **Zashchita ot oshibok:** Korrektnaya obrabotka nepravilnogo vvoda (simvoly, pustye polya).

---

## 🛠 Tehnologii

* **Python 3.x**
* **CustomTkinter** — graficheskiy interfeys (GUI)
